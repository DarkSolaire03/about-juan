## Tech

A single `index.html` file with inline CSS/JS — no build step. Dark charcoal theme with teal/blue and ember accents, sticky nav, smooth scrolling, mobile-friendly. A `.nojekyll` file is included so GitHub Pages serves the site as-is.

GitHub Pages is enabled from the `main` branch root.
